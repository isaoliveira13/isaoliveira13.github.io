Sobre mim

Qualidade é cuidado com quem vai usar.

Repositório de Scripts

Uma biblioteca para organizar scripts de teste Playwright e Cypress: cada script vira um card com avatar, ambiente, cenário, tela do CRM coberta e etiquetas. Dá para montar suítes, revisar rascunhos com histórico de versões, acompanhar a cobertura por tela e emitir um checklist de aprovação em PDF. Na versão interna, o botão “Rodar” dispara o teste de verdade num workflow do GitHub Actions.

QA Simulator Chat

Um motor para testar avatares de IA de atendimento simulando conversas reais: monto um cenário, a conversa roda turno a turno contra o avatar e, no fim, fica salvo um relatório com resultado, transcrição completa, tempo e sentimento. Roda com várias personas de uma vez, em lote, e tem heurísticas que detectam quando o avatar entra em loop e barram um “sucesso” sem evidência no texto. Na versão interna, conversa com a API real e usa a OpenAI no papel do cliente.
